# 문제 해결 사례 제목

- 작업일: YYYY-MM-DD 또는 확인 불가
- 문서 작성일: YYYY-MM-DD
- 관련 커밋: `hash`
- 상태: 완료 / 일부 완료 / 보류

## 문제

관찰된 현상과 실제 위험을 적는다.

## 원인

코드 구조, 데이터 모델, 트랜잭션 또는 운영 환경 관점에서 원인을 적는다.

## 해결

핵심 설계와 구현 내용을 적는다.

## 기술 선택과 트레이드오프

### 선택한 방법

선택 이유와 얻는 점을 적는다.

### 검토한 대안

선택하지 않은 이유를 적는다.

### 감수한 비용

복잡도, 운영 비용, 확장 제약을 적는다.

## 검증

단위·영속성·통합·동시성·성능 테스트와 확인 결과를 적는다.

## 결과

변경 전후 차이와 재발 방지 효과를 적는다. 측정하지 않은 수치는 만들지 않는다.

## 후속 과제

현재 요구사항 때문에 보류한 개선 사항을 적는다.

## 포트폴리오 요약 후보

이 사례를 2~3문장으로 요약한다.
