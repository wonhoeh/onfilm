## 학습 내용 기록 원칙

사용자가 대화 내용을 붙여 주고 기록을 요청하면 원문을 보존하되, 평소에는 핵심을 먼저 읽을 수 있도록 다음 구조로 정리한다.

- 기본 화면: 핵심 설명, 짧은 코드, 설계 이유와 주의점
- 상세 펼치기: 반복 설명, 예시, 코드, 질문에 대한 보충 설명을 포함한 전체 원문
- 별도 검토 메모: 원문 표현의 기술적인 오류나 보완 사항

핵심 설명을 추가하더라도 상세 원문을 임의로 삭제하거나 요약으로 대체하지 않는다. 원문에는 제목 단계, 줄바꿈, 코드 블록, 표 등 읽기 위한 서식만 적용한다. 접기·펼치기는 이를 지원하는 Markdown 미리보기에서 사용한다. 이미 작성된 원문 문서는 개편을 요청받았을 때 이 구조를 적용한다.

이후 학습 문서는 아래 번호를 사용한다.

- `01`: 회원가입·로그인·토큰 관리
- `02`: 프로필 관리와 개인 페이지 공유
- `03`: 필모그래피와 작품 참여 역할 관리
- `04`: 프로필 이미지·갤러리 파일 관리
- `05`: 스토리보드 관리
- `06`: 영화·장르·트레일러 관리
- `07`: 영상 업로드·인코딩·작업 상태 관리
- `08`: 운영·모니터링·성능·배포
